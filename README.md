# Nexora – Game Marketplace (front-end demo)

A cinematic, dark-themed game marketplace built as a single self-contained `index.html` (vanilla HTML/CSS/JS, no build step).

## Features
- Cinematic hero launcher, trending gallery, editor's choice, deals, rankings
- Discover with filters and sorting, search autocomplete
- Game pages with seller price comparison and reviews
- Cart, coupon (`PLAY10`), 3-step checkout, order confirmation
- Buyer account (orders, library, support), seller dashboard, admin panel (log in as `admin`)

## Run
Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → `main` / root).

## Notes
Auth, payments and data are simulated in the browser (localStorage). Covers are generated art; set the `img` field per game to use real cover URLs.
